# SQL Data Analysis

## Objective
Use SQL queries to extract and analyze data from an ecommerce database using MySQL.

## Tool Used
- MySQL Workbench

## Database
- Ecommerce database
- Tables: customers, products, orders

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate functions such as SUM and AVG
- INNER JOIN
- LEFT JOIN
- Subqueries
- Views
- Indexes
- HAVING

## Analysis Performed
- Retrieved customer, product, and order data.
- Filtered products by category.
- Sorted products by price.
- Calculated revenue by product category.
- Calculated average revenue per customer.
- Combined customer, order, and product information using joins.
- Identified products priced above the average product price.
- Created a customer order summary view.
- Created an index on order date.
- Filtered categories based on revenue using HAVING.

This project helped me practice SQL querying, data aggregation, joins, subqueries, views, indexes, and basic ecommerce data analysis using MySQL.
